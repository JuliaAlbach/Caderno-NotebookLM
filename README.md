# -Treinando-uma-IA-de-Aprendizagem-Explore-o-Poder-do-NotebookLM
Aplicação prática de IA generativa com NotebookLM, incluindo curadoria de conhecimento, engenharia de prompts, documentação do processo de aprendizagem e consolidação de conteúdo em formato de guia de estudos. Projeto realizado no contexto do Bootcamp Bradesco - GenAI, Dados &amp; Cyber.
